contract GlamHouseProperty is ERC3643, Ownable {

  // === DONNÉES DU BIEN ===
  string public propertyName;
  string public propertyLocation;
  uint256 public totalTokens;
  uint256 public pricePerToken;
  string public documentHash; // IPFS hash des docs légaux

  // === KYC OBLIGATOIRE ===
  mapping(address => bool) public kycApproved;

  // === DISTRIBUTION DES LOYERS ===
  function distributeRent() external onlyOwner {
    // Distribue proportionnellement aux détenteurs
    for (uint i; i < holders.length; i++) {
      uint256 share = (rentPool * balanceOf(holders[i])) / totalSupply();
      payable(holders[i]).transfer(share);
    }
  }

  // === DOCUMENTS BLOCKCHAIN ===
  function updateDocuments(string _hash) external onlyOwner {
    documentHash = _hash; // L'admin ajoute des docs → IPFS → hash on-chain
    emit DocumentsUpdated(_hash, block.timestamp);
  }
}

Questions Fréquentes

Tout ce que vous devez savoir sur la tokenisation MyGlamHouse

Qu'est-ce qu'un token immobilier exactement ?

Un token immobilier est un titre numérique qui représente une part de propriété d'un bien immobilier réel — un peu comme des parts de copropriété, mais sous forme digitale. Chaque token vous donne droit à une part proportionnelle des revenus locatifs et de la plus-value du bien. Si vous préférez un investissement classique par virement bancaire, c'est tout à fait possible pour chacun de nos projets — contactez-nous directement.

Est-ce légal en France ?

Oui, totalement. La loi PACTE (2019) et le règlement européen MiCA encadrent les Security Token Offerings (STO). MyGlamHouse opère sous le standard ERC-3643 avec enregistrement AMF et conformité KYC/AML complète. Nous travaillons avec des avocats spécialisés en droit crypto et immobilier.

Quel est le montant minimum d'investissement ?

À partir de 500€ pour les equity tokens (capital de l'entreprise), 1 400€ pour l'ÉcoVillage, et 1 780€ pour la Résidence Senior Normandie. Vous pouvez acheter autant de tokens que vous le souhaitez.

Comment sont distribués les loyers ?

Les loyers sont collectés par notre gestionnaire, puis distribués automatiquement via smart contract chaque trimestre. La distribution est proportionnelle au nombre de tokens détenus. Tout est transparent et vérifiable sur la blockchain. Pas besoin de faire quoi que ce soit — les revenus arrivent directement dans votre wallet.

Puis-je revendre mes tokens ?

Oui. Un marché secondaire est intégré à notre plateforme. Vous pouvez proposer vos tokens à la vente à tout moment. Les acheteurs potentiels doivent être vérifiés KYC. La transaction se fait en peer-to-peer via smart contract — instantanée et sécurisée.

Quelle est la fiscalité applicable ?

En France, les revenus issus de tokens immobiliers (Security Tokens) sont soumis au PFU (Prélèvement Forfaitaire Unique) de 30% — aussi appelé "flat tax". Cela inclut 12,8% d'impôt sur le revenu + 17,2% de prélèvements sociaux. C'est identique à la fiscalité des dividendes d'actions. Consultez votre conseiller fiscal pour votre situation personnelle.

Et si le projet ne se réalise pas ?

Si le financement n'atteint pas son objectif minimum, tous les fonds sont automatiquement retournés aux investisseurs via le smart contract. C'est inscrit dans le code et ne peut être modifié. Les fonds sont séquestrés sur un compte dédié jusqu'à la validation du projet.
